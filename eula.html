Section 6. Express Authorization of System-Level Operations & Win32 API Permissions

Because NoteStrata™ embeds interactive sticky notes directly onto the Windows desktop environment, the Windows APIs utilized by the Software technically have access to system-level capabilities necessary for the Software's features (though NoteStrata™ does not use those capabilities to collect or transmit personal information). By using the Software, You expressly authorize the Software to perform the following system operations on Your Device:
6.1 Desktop Wallpaper Modification (SystemParametersInfoW): Read Your current Windows desktop wallpaper path or cached transcoded wallpaper, maintain a local backup copy of Your original wallpaper (original_wallpaper_backup.png), generate a composite image (active_sticky_wallpaper.bmp) containing Your rendered sticky notes, and apply it as Your active Windows desktop background.
6.2 Low-Level Desktop Mouse Hook (WH_MOUSE_LL): Install and maintain a local Windows low-level mouse hook (SetWindowsHookExW) solely to detect left mouse button clicks occurring directly over the Windows Desktop surface (Progman, WorkerW, and SHELLDLL_DefView) whose screen coordinates intersect with active sticky note checklist items ("Click-to-Check").
6.3 Global Keyboard Shortcut Registration (Alt+S or Custom Hotkey): Register and listen for a global keyboard shortcut (RegisterHotKey) across Your Windows session to toggle sticky note visibility on Your desktop wallpaper.
6.4 Screen Pixel Color Sampling (GetDC / GetPixel): Read the RGB hexadecimal color value of the screen pixel under Your cursor when You explicitly activate the Screen Color Eyedropper tool.
6.5 Windows Startup Registration (HKCU\...\Run): Manage a user-level registry value under HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run so NoteStrata™ can launch in the system tray when You log into Windows.
6.6 Local File System Storage & OS Spell Checking: Create, read, write, and delete files within %USERPROFILE%\.notestrata and invoke the Windows OS ISpellChecker COM interface for spelling suggestions through the Windows operating system's spell-checking API.
